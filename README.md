# ECHOES Consultation Profile / Occupation Analysis Redirect Page

This repository contains a simple GitHub Pages site used to redirect visitors to the current temporary URL of the interactive app for profile / occupation analysis (WP4). 

## Purpose

The app is hosted through a temporary application endpoint, which may change over time. This GitHub Pages site provides a stable public link that can be shared with users, while allowing the redirect target to be updated whenever the dashboard URL changes.

## How it works

The site serves a minimal HTML page that automatically redirects visitors to the active app URL.

## Repository contents

- `index.html` — the redirect page
- `README.md` — this file

## Notes

- This repository does not host the app itself.
- It only provides a stable entry point that forwards users to the current app.
